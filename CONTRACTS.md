## 1. Provenance — the core of this project

Every fact that reaches a user carries where it came from. This is the ticket's requirement
("cite the source URL next to each extracted fact") expressed as a type, so it cannot be skipped.

```ts
export type Confidence =
  | "confirmed"      // ≥2 independent sources agree
  | "official"       // stated by azuraworld.com or a Cebeci Group domain
  | "single_source"  // one source only, uncontradicted
  | "conflicted"     // sources disagree; see conflictsWith
  | "inferred"       // derived by computation from confirmed facts; note explains how
  | "gap"            // not established — value MUST be null

export interface SourceRef {
  url: string
  /** Publisher label for UI, e.g. "Seaside Alanya" */
  publisher: string
  /** ISO 8601. When the harvester actually retrieved this. */
  fetchedAt: string
  /** sha256 of the stored raw snapshot under sources/raw/ */
  snapshotHash: string
  tier: SourceTier
}

/** Resolution order when sources disagree. Lower number wins the DISPLAY value. */
export type SourceTier =
  | 1 // official        — azuraworld.com
  | 2 // developer       — cebecigroup.com, alanyacebeci.com
  | 3 // hotel operation — azuraworldhotel.com
  | 4 // portal          — terra, alanya-home, housearch, haspo, seaside, realtygroup, ivm
  | 5 // review/booking  — tripadvisor, booking, agoda, onthebeach
  | 6 // press/secondary — enspride, turizmguncel, kalinka, cestate

export interface SourcedFact<T> {
  value: T | null
  sources: SourceRef[]
  confidence: Confidence
  /** Populated iff confidence === "conflicted". Never empty when it is. */
  conflictsWith?: Array<{ value: unknown; source: SourceRef }>
  /** Required for "inferred" and "gap". Explains the derivation or the absence. */
  note?: string
}
```

**Invariants — enforced by `scripts/verify-evidence.mjs` (W0-B) and tested in W4-D:**

1. `confidence === "gap"` ⟹ `value === null` **and** `note` is non-empty
2. `confidence === "conflicted"` ⟹ `conflictsWith.length ≥ 1`
3. `confidence === "confirmed"` ⟹ `sources.length ≥ 2` with **distinct hosts**
4. `confidence === "inferred"` ⟹ `note` explains the computation
5. `sources.length === 0` is only legal when `confidence === "gap"`
6. Every `snapshotHash` resolves to a real file under `sources/raw/`

> Rule 6 is why the harvester stores raw HTML. A citation you cannot re-open is not a citation.

## 3. RBAC — frozen, W1-A and W1-B must agree exactly

Eleven roles. **The TS union and the SQL enum are the same list in the same order.**

```ts
export const roles = [
  "admin", "manager", "accountant", "staff", "owner", "tenant",
  "guest", "service_provider", "child_owner", "child_tenant", "child_guest",
] as const

export const resources = [
  "dashboard", "listings", "units", "leads", "buyer_pipeline", "deals",
  "tickets", "activities", "calendar", "documents", "compliance",
  "finance", "wallet", "vendor_invoices", "reports", "users", "settings",
  "communications", "hotel", "reviews", "evidence",
] as const

export const actions = [
  "view", "create", "update", "delete", "manage", "export", "approve", "assign",
] as const

export type Role = (typeof roles)[number]
export type Resource = (typeof resources)[number]
export type Action = (typeof actions)[number]
export type Permission = `${Resource}:${Action}`

export const roleLevel: Record<Role, number> = {
  admin: 90, manager: 70, accountant: 60, staff: 40,
  owner: 20, tenant: 10, service_provider: 30, guest: 5,
  child_owner: 15, child_tenant: 8, child_guest: 3,
}
```

**Additive-authority rule:** the five added roles (`guest`, `service_provider`, `child_*`) sit
strictly below the canonical six and may **never** widen an existing role's permissions.

**`evidence` is Azura-specific** — it gates the source/conflict cockpit. `manager` and above
may `view`; only `admin` may `manage`.

## 4. Repository envelope

Every repository function returns this. Non-negotiable — it is how the app runs without a
database, and how you debug data problems.

```ts
export interface RepositoryResult<T> {
  data: T
  source: "supabase" | "local-seed"
  /** Present when source === "local-seed" AND Supabase was expected. Explains the fallback. */
  degradedReason?: string
  fetchedAt: string
}
```

**Rules:** never throw for "Supabase not configured" — fall back and label it. Do throw on a
*configured* Supabase returning a real error; a silent fallback would hide an outage.

## 5. API envelope

```ts
export type ApiResponse<T> =
  | { ok: true; data: T; source: "supabase" | "local-seed"; requestId: string }
  | { ok: false; error: ApiError; requestId: string }

export interface ApiError {
  code:
    | "unauthorized" | "forbidden" | "not_found" | "validation_failed"
    | "rate_limited" | "conflict" | "persistence_unavailable" | "upstream_failed"
  message: string          // safe for display; never contains internals
  details?: Record<string, string>
  retryable: boolean
}
```

**Status mapping** — fixed, tested by the contract suite:

| code | HTTP |
|---|---|
| `unauthorized` | 401 |
| `forbidden` | 403 |
| `not_found` | 404 |
| `validation_failed` | 422 |
| `conflict` | 409 |
| `rate_limited` | 429 |
| `persistence_unavailable` | 503 |
| `upstream_failed` | 502 |

**Never 500 for a handled condition.** A 500 means we have a bug, and W4-C treats any reachable
500 as a High finding.

## 6. AI

```ts
export interface AiRequest { message: string; conversationId?: string; locale: Locale }

export interface AiResponse {
  reply: string
  source: "gateway" | "deterministic-fallback" | "rbac-guard"
  /** Every factual claim traced to dataset provenance. Empty ⟹ reply asserted no facts. */
  citations: SourceRef[]
  model: string | null
  refused: boolean
  refusalReason?: "out_of_scope" | "insufficient_permission" | "no_grounding" | "unsafe_request"
}
```

**Hard rules:**
1. RBAC decision **before** the gateway call. Denied ⟹ `source: "rbac-guard"`, no outbound request.
2. Gateway unreachable or unconfigured ⟹ `source: "deterministic-fallback"`. **Never 5xx.**
3. A claim the dataset cannot ground ⟹ refuse with `no_grounding`. The concierge does not
   speculate about a competitor's prices.
4. Input ceiling 2000 chars, validated before anything else.
5. The system prompt forbids executing financial/access/permission actions — recommend only.

## 8. Anti-patterns — rejected in review

| Don't | Do |
|---|---|
| `price: number` | `askingPrice: SourcedFact<Money>` |
| Picking the "most likely" value when sources disagree | `confidence: "conflicted"` + a `Finding` |
| `catch { return [] }` | Return `RepositoryResult` with `degradedReason` |
| `role === "admin" \|\| role === "manager"` | `hasPermission(role, "evidence:view")` |
| Throwing raw Supabase errors to the client | Map to `ApiError`; log detail server-side only |
| A number in JSX with no source | Render through the provenance component from W1-D |
| `as any` to satisfy `SourcedFact` | Fix the data shape |

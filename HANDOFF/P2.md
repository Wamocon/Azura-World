## 3. What was deliberately kept

**The sync badge and `Demo-Daten`**, as instructed. Untouched.

**Every honesty rule that is not about provenance**, per the brief and `PIVOT.md` §2:

- A missing value still renders **"Keine Angabe"**, never blank and never `0`. `ProvenanceValue`
  still reads through the `confidence === "gap"` guard rather than from `fact.value`, so a dataset
  that violates its own invariant still cannot leak a number onto the screen.
- Writes with no database still return **503**, never a fake success.
- The public report form still says *"Nicht gespeichert … es gibt keine Nummer."*
- No unconfigured integration is shown as healthy; the communications module still says
  *"Nicht versendet, Anbieter nicht konfiguriert."*
- Activity capacity still says **"Belegung nicht bekannt"** rather than showing zero.

**Two German words that look like provenance and are not**, checked individually and kept:

- **"Belegung"** — occupancy. Hotel occupancy, activity capacity, room tables.
- **"Beleg"** — a receipt or voucher number. `dashboard.finance.columns.reference`,
  `dashboard.payments.console.referenceHint`.

**`dashboard.compliance.*`** keeps its "Belegt / Ohne Beleg bestanden" vocabulary. That is
compliance evidence — *can we show this check was actually performed* — which is a real ERP concept
and a feature of the product, not source provenance about the client. Judgement call, flagged here
so it can be reversed cheaply if the pitch disagrees.

## 4. What is still there, and what it would take

Pass 1 was scoped to what the client can see. A sweep of the four catalogues for provenance
vocabulary found **119 strings** at the start; the visible ones are done. What remains is in three
groups.

### 4.1 Dead labels — harmless, remove in pass 2

The `evidence.*` and `landing.provenance.*` bundles (~30 strings) are still passed as props to
components that now render `null`. They cost nothing and are invisible. They disappear when pass 2
deletes the call sites.

### 4.2 Surfaces not reached in this pass — **check before the pitch if they are on the route**

| Surface | What is still there |
| ------- | ------------------- |
| **`/de/concierge`** | The subtitle and refusal copy were reframed, but the **answers themselves** still cite sources: `sourcesLabel` "Genutzte Quellen", `openSource`, `refusalNote`, and the answer builder in `lib/ai-responses.ts` composes source lists. This is the single biggest remaining surface and it is public |
| **`/de/report`** | The public report still has `sectionSources` "Quellen" and `report.empty` "Keine belegten Daten" |
| **`/de/hotel`** | Leads and meta reframed; `hotel.provenance.*` and `hotel.distance.explanation` still carry conflict wording |
| **`dashboard/reviews`** | Lead reframed; `noAverageNote` and `verdict.titleGap` still explain why no average is computed in provenance terms |
| **`dashboard/reports`** | The `evidence_coverage` report was removed; `carriesProvenance` "Mit Quellenangabe" and `csv.source` "Datenherkunft" remain |
| **`dashboard/hotel`** | `facts.brandNotStated` no longer names finding **F-018**, but other panels still reference findings |

**The concierge is the one I would look at first.** It is public, it is on the demo path, and it
answers a price question by listing five publishers and their disagreement. Reframing it is not a
copy edit — `lib/ai-responses.ts` and `lib/ai-concierge.ts` build the citation list structurally.
That is a bigger change than pass 1's remit and it needs a decision about what the concierge is
*for* in the new framing.

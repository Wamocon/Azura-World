## 4. New tests handed to W4-A

The brief calls this the most valuable output. Twelve, one per finding automation should have
caught; each closes a class rather than an instance. Full text in `MANUAL-TEST-REPORT.md` §8.

The three worth doing first, because each would have caught a blocker:

1. **Production auth reachability** — a bad-password sign-in must reach *invalid-credentials*, never
   *not-configured*. Catches M-001.
2. **Auth select-list contract** — issue `lib/auth.ts`'s literal select list against PostgREST and
   fail on non-200. Catches M-002 and would have caught it the day the columns drifted.
3. **No cross-currency arithmetic in a finding message** — a `ratio`/`x`/`%` derived from
   `competingValues` spanning more than one currency fails the build. Catches M-003.

And the cheapest with the widest reach: **no visible text may match
`/^(common|dashboard|auth|landing)\.[a-z]/`** on any route × locale. That one alone catches M-005
and M-009, and would have caught the same defect I found in my own modules during W3-E.

- **Pass 10** — XSS did not execute, prompt injection was refused, the `?next=` allowlist held 4/4.
- **Pass 11** — reduced motion loses no content; 12/12 tab hops had a visible focus ring.
- **Pass 12** — no horizontal scroll at 375px on three dashboard modules; Cyrillic renders clean.

## 6. What was not tested, and why it could not be

Everything in this list has the same root cause as M-001, and all of it becomes testable the moment
that one file moves:

- Sign-in as any role through the real auth path (also blocked by M-002)
- Saving a German-formatted amount and checking what was stored
- Editing a posted ledger entry; double-clicking a payment submit
- A ticket through its lifecycle, and whether the API rejects an invalid transition — the 503
  short-circuits before the check, so **the W3-E gap remains unverified in a running app**
- Public report idempotency on replay
- Booking the last capacity slot — additionally blocked by the absent `activity_bookings` table

Independently unavailable: axe-core and Lighthouse (not installed), a real screen reader, real
mobile hardware, and an `.ics` opened in Outlook or Apple Calendar.

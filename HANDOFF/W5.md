## 5. A process hazard that produced two false results today

Twice this session a **stale server from another git worktree** held the port a gate wanted, and
the gate attached to it instead of failing:

- `csp-probe` reported `25 pass · 5 fail` with *"is NODE_ENV=production? this gate is meaningless
  in dev"* — it was probing a dev server from another worktree. Clean re-run: `30 pass · 0 fail`.
- My first `next start` failed with `EADDRINUSE` and I measured `anon → /de/dashboard → 200`. I was
  one step from filing a catastrophic auth bypass. On a clean port the same probe returns
  **307 → /de/login** for every role including `admin`, which is correct.

Six windows share one machine and a port convention. **A harness that silently measures somebody
else's server is worse than one that fails**, because its output looks like a finding. T-005.

M-005 first and this is the demo's closing moment.
